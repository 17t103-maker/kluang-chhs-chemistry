11.1 铝的性质（存在形态、物理特性、两性反应与铝热反应） 任务一

1. 自然存在与地壳丰度：
铝（Aluminium, Al）元素占地壳总质量的 7.73% ，是地壳中含量 最多 的金属元素（在地壳全部元素中仅次于氧和硅排第三位）。在自然界中均以 化合态 形式存在（如铝土矿主要成分为 Al₂O₃）。铝位于元素周期表中第 3 周期、第 IIIA 族 ，原子的核外最外层电子排布式为 3s² 3p¹ 。

11.1.2 铝的化学性质（点击查看方程式产物与状态）

1. 与非金属及水的反应：

  • 与氧气常温氧化：表面迅速生成一层致密坚固的 Al₂O₃ 氧化膜，阻止内部金属继续被氧化。
  • 在纯氧中加热燃烧：剧烈燃烧，放出大量热并发出耀眼白光：
    4Al(s) + 3O₂(g) —点燃→ 2Al₂O₃(s)
  • 与卤素、硫化合：
    • 2Al(s) + 3Cl₂(g) —Δ→ 2AlCl₃(s)
    • 2Al(s) + 3S(s) —Δ→ Al₂S₃(s)
  • 熔融铝与水剧烈反应：
    2Al(l) + 3H₂O(l) → Al₂O₃(s) + 3H₂(g)↑

2. 钝化现象（Passivation）与微观动态探究：
在常温下，铝遇 浓硝酸或浓硫酸 时，表面最外层原子被迅速氧化生成一层极薄而致密坚固的氧化物薄膜，阻碍内部金属进一步发生反应，这种现象称为钝化。因此工业上常用 铝制槽罐/容器 来储运冷浓硫酸或冷浓硝酸。

3. 两性反应：与酸和强碱的反应：
铝既能与非氧化性强酸反应，也能与强碱溶液反应放出氢气，体现特殊的两性金属性！

  • 与非氧化性酸反应（稀盐酸）：
    • 化学方程式：2Al(s) + 6HCl(aq) → 2AlCl₃(aq) + 3H₂(g)↑
    • 离子方程式：2Al(s) + 6H⁺(aq) → 2Al³⁺(aq) + 3H₂(g)↑
  • 与强碱溶液反应（NaOH 溶液）：
    • 化学方程式：2Al(s) + 2NaOH(aq) + 2H₂O(l) → 2NaAlO₂(aq) + 3H₂(g)↑
    • 离子方程式：2Al(s) + 2OH⁻(aq) + 2H₂O(l) → 2AlO₂⁻(aq) + 3H₂(g)↑
❓ 核心计量规律：等质量的铝分别与足量稀盐酸和足量 NaOH 溶液反应，产生气体的比例是多少？消耗酸碱的比例是多少？
• 产生 H₂ 物质的量之比：根据得失电子守恒（2Al ~ 3H₂），生成 H₂ 的体积之比为 1 : 1！
• 消耗 HCl 与 NaOH 物质的量之比：消耗 HCl 与 NaOH 之比为 3 : 1（因 6HCl ~ 2Al ~ 2NaOH）。
11.1.3 铝热反应（Thermite Reaction）原理与真实实验视窗

把铝粉和某些难熔金属氧化物（如 Fe₂O₃、Cr₂O₃、V₂O₅、MnO₂）的混合物称为铝热剂。用镁条和氯酸钾引燃后发生剧烈氧化还原反应，放出巨大热量使生成的金属熔化为铁水流出，广泛应用于野外无缝铁轨焊接与冶炼难熔金属。

  • 焊接铁轨核心反应：2Al(s) + Fe₂O₃(s) —高温→ 2Fe(l) + Al₂O₃(l)
  • 冶炼金属铬反应：2Al(s) + Cr₂O₃(s) —高温→ 2Cr(l) + Al₂O₃(l)

11.2 铝的重要化合物（氧化铝、氢氧化铝与明矾复盐） 任务二
1. 氧化铝（Al₂O₃）—— 典型的两性氧化物

氧化铝是白色难熔固体（熔点 2054℃ ），硬度大，自然界中的刚玉、红宝石（含微量 Cr）、蓝宝石（含微量 Fe 和 Ti）主要成分均为 Al₂O₃。它既能溶于强酸生成铝盐，又能溶于强碱生成偏铝酸盐，属于两性氧化物：

  • 与强酸反应（稀硫酸）：
    • 化学方程式：Al₂O₃(s) + 3H₂SO₄(aq) → Al₂(SO₄)₃(aq) + 3H₂O(l)
    • 离子方程式：Al₂O₃(s) + 6H⁺(aq) → 2Al³⁺(aq) + 3H₂O(l)
  • 与强碱反应（NaOH 溶液）：
    • 化学方程式：Al₂O₃(s) + 2NaOH(aq) → 2NaAlO₂(aq) + H₂O(l)
    • 离子方程式：Al₂O₃(s) + 2OH⁻(aq) → 2AlO₂⁻(aq) + H₂O(l)
2. 氢氧化铝（Al(OH)₃）—— 两性氢氧化物与阻燃剂

氢氧化铝是白色胶状不溶于水的沉淀，吸附能力强。具有独特的双向电离平衡机制：

酸式电离：AlO₂⁻ + H⁺ + H₂O ⇌ Al(OH)₃(s) ⇌ Al³⁺ + 3OH⁻ ：碱式电离

  • 实验室制备标准原则：可溶性铝盐必须与弱碱（氨水）反应，严禁使用过量强碱：
    • 化学方程式：Al₂(SO₄)₃(aq) + 6NH₃·H₂O(aq) → 2Al(OH)₃(s)↓ + 3(NH₄)₂SO₄(aq)
    • 离子方程式：Al³⁺(aq) + 3NH₃·H₂O(aq) → Al(OH)₃(s)↓ + 3NH₄⁺(aq)
  • 溶解于强酸：Al(OH)₃(s) + 3H⁺(aq) → Al³⁺(aq) + 3H₂O(l)
  • 溶解于强碱：Al(OH)₃(s) + OH⁻(aq) → AlO₂⁻(aq) + 2H₂O(l)
  • 受热分解与阻燃机理：2Al(OH)₃(s) —Δ→ Al₂O₃(s) + 3H₂O(g) （受热剧烈吸热降低温度，生成水蒸气稀释氧气，无毒无公害无烟阻燃剂）。
3. 硫酸铝钾与明矾（KAl(SO₄)₂·12H₂O）净水原理与微观探究

明矾化学式为 KAl(SO₄)₂·12H₂O ，是由两种不同的金属阳离子（K⁺, Al³⁺）与硫酸根阴离子组成的复盐。
• 净水原理解析：明矾溶于水电离出 Al³⁺ 离子，Al³⁺ 水解生成具有巨大表面积与强吸附能力的 Al(OH)₃ 胶体 ：
Al³⁺(aq) + 3H₂O(l) ⇌ Al(OH)₃(胶体) + 3H⁺(aq)，吸附水中微小泥沙悬浮颗粒聚沉。

11.3 铝的冶炼（工业流程、冰晶石助熔电解机理） 任务三
1. 铝土矿提纯为纯净氧化铝（拜耳法工艺流程）

铝土矿主要成分为 Al₂O₃，并含有 Fe₂O₃、SiO₂ 等杂质。工业提取流程如下：

① 碱溶：加过量 NaOH 溶液溶解 Al₂O₃（Fe₂O₃ 不溶过滤除去，作为红泥残渣）：
    Al₂O₃(s) + 2NaOH(aq) → 2NaAlO₂(aq) + H₂O(l)
② 酸化析出沉淀：向滤液中通入过量 CO₂ 气体沉淀析出 Al(OH)₃：
    NaAlO₂(aq) + CO₂(g) + 2H₂O(l) → Al(OH)₃(s)↓ + NaHCO₃(aq)
③ 灼烧分解：高温煅烧沉淀获得高纯度 Al₂O₃：
    2Al(OH)₃(s) —高温灼烧→ Al₂O₃(s) + 3H₂O(g)
2. 工业电解熔融氧化铝原理
  • 工业总反应：2Al₂O₃(l) ——通电(冰晶石, 1000℃)——> 4Al(l) + 3O₂(g)↑
  • 为什么必须加入冰晶石（Na₃AlF₆）？
    纯 Al₂O₃ 的熔点高达 2054℃ ，加入冰晶石作为助熔剂后，可在 950~1000℃ 形成熔盐共熔体进行电解，大幅降低能耗与设备成本！
  • 阳极碳块定期更换的原因：阳极生成的高温 O₂ 会不断氧化烧蚀碳阳极石墨块（C + O₂ → CO₂），因此需定期补充更换阳极。
