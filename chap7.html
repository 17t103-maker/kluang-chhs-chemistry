🔗 配位键形成微观互动模拟器 (Coordinate Bond)

配位键本质规律

• 成键条件：一方原子拥有孤对电子，另一方原子/离子具备容纳电子的空轨道。
• 特点说明：成键后，铵根离子内部 4 个 N-H 键的键长、键能完全相同，化学性质无差别。

💧 7.2 分子间作用力 (Intermolecular Forces)

7.2.1 范德华力 (微弱静电引力) 及 5 大影响因素全景表

影响因素 内在微观物理规律 对比典型实例 熔沸点规律及原因剖析
1. 式量 (分子量) 结构相似时，式量越大，电子数目越多，电子云越易变形（极化率高），范德华力越强 卤素单质：F₂ < Cl₂ < Br₂ < I₂ 沸点：F₂ (-188℃) < Cl₂ (-34℃) < Br₂ (59℃) < I₂ (184℃)，由气态渐变为固态
2. 分子极性 式量相近时，极性分子的固有偶极引力强于非极性分子的瞬时偶极 相对分子量均为 28 的 N₂ 与 CO 沸点：非极性 N₂ (-195.8℃) < 极性 CO (-191.5℃)，极性分子范德华力更大
3. 分子中原子数目 同系物中原子数越多，分子间相互接触面积越大，范德华力越强 烷烃同系物：CH₄ < C₂H₆ < C₃H₈ < C₄H₁₀ 沸点随碳链增长而显著升高：甲烷 (-161.5℃) < 丁烷 (-0.5℃)
4. 分子中电子数目 稀有气体原子核外电子数越多，电子云变形性越大，色散力显著增大 稀有气体：He < Ne < Ar < Kr < Xe 沸点依次升高：氦 (4.2 K) < 氖 (27.1 K) < 氪 (119.7 K) < 氙 (165 K)
5. 分子形状与支链 同分异构体中，支链越多，分子越趋向球形，接触表面积越小，范德华力越小 戊烷异构体：新戊烷 < 异戊烷 < 正戊烷 沸点：新戊烷 (9.5℃, 气态球形) < 异戊烷 (28℃) < 正戊烷 (36.1℃, 伸展链状)

7.2.2 氢键 (X-H···Y) 动态展示与氢化物沸点反常图谱

氢键动态网络

水分子 (H₂O) 间氢键特征

• 成键机制：强极性 O-H 键中，氢原子核几乎裸露 ($\delta^+$)，强烈吸引相邻水分子中氧原子的孤对电子 ($\delta^-$)。
• 键能比值：共价键 : 氢键 : 范德华力 ≈ 100 : 10 : 1。
• 物理影响：显著提高熔沸点（汽化需克服氢键）；冰中形成 4 氢键开放空腔，密度反常小于液态水。

🧊 7.3 晶体类型及其 3D 晶胞结构探究

🖱️ 拖拽 3D 旋转观察微观晶胞框架

离子晶体 (NaCl)

• 构成微粒：Na⁺ 阳离子与 Cl⁻ 阴离子
• 微粒间作用力：离子键
• 导电本质：固态不导电；熔融或水溶液破坏离子键产生自由离子而导电。
• 晶体特性：硬而脆，熔沸点高，无独立单个分子。
