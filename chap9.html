9.1.2 钠和钾的化学性质

1. 与非金属单质（氧气、卤素）的反应：

  • 常温与氧气缓慢氧化：表面迅速变暗失去光泽[cite: 1]。
    • 钠：4Na(s) + O₂(g) → 2Na₂O(s)（白色固体氧化钠） [cite: 1]
    • 钾：4K(s) + O₂(g) → 2K₂O(s)（微黄白色固体氧化钾） [cite: 1]
  • 在空气中加热燃烧：剧烈燃烧，生成过氧化物或超氧化物[cite: 1]。
    • 钠：2Na(s) + O₂(g) —Δ→ Na₂O₂(s)（淡黄色固体过氧化钠，黄色火焰） [cite: 1]
    • 钾：K(s) + O₂(g) —Δ→ KO₂(s)（橙黄色固体超氧化钾，淡紫色火焰） [cite: 1]
  • 与卤素单质（Cl₂、Br₂、I₂）直接化合：
    • 钠在氯气中燃烧：2Na(s) + Cl₂(g) —点燃→ 2NaCl(s)（大量白烟，耀眼黄色火焰） [cite: 1]
    • 钾与卤素化合：2K(s) + Cl₂(g) —点燃→ 2KCl(s)（化合极其剧烈，室温接触即可能引发爆炸） [cite: 1]

2. 与水及酸反应：

  • 与水反应：
    • 钠与水：2Na(s) + 2H₂O(l) → 2NaOH(aq) + H₂(g)↑ [cite: 1]
    • 钾与水：2K(s) + 2H₂O(l) → 2KOH(aq) + H₂(g)↑ [cite: 1]
  • 与酸反应：比水更剧烈，极易发生爆炸式反应：
    • 钠与盐酸：2Na(s) + 2HCl(aq) → 2NaCl(aq) + H₂(g)↑ [cite: 1]
    • 钾与盐酸：2K(s) + 2HCl(aq) → 2KCl(aq) + H₂(g)↑ [cite: 1]

9.1.3 工业制取金属钠与金属钾的反应机理与原理
  • 工业制钠（Down 槽电解熔融 NaCl）：
    • 总反应：2NaCl(l) ——电解(580~600℃)——> 2Na(l) + Cl₂(g)↑ [cite: 1]
    • 阳极 (石墨)：2Cl⁻ - 2e⁻ → Cl₂(g)↑ (氧化反应)
    • 阴极 (铁)：2Na⁺ + 2e⁻ → 2Na(l) (还原反应)
    • 科学要点剖析：在 580~600℃ 电解温度下，生成的金属钠呈现液态（熔点 97.8℃）而非气体[cite: 1]！由于液态钠的密度（约 0.8 g/cm³）小于熔盐体系，钠会在阴极形成小液滴并上浮汇集流出；中间通过铁丝网隔膜机械阻隔，防止液态钠扩散到阳极与黄绿色氯气重新化合。
  • 工业制钾（高温钠热还原法）：
    • 反应原理：KCl(l) + Na(l) ⇌ NaCl(l) + K(g)↑ (850℃) [cite: 1]
    • 勒夏特列原理应用：在 850℃ 下，钾的沸点（759℃）低于钠的沸点（883℃）[cite: 1]，生成的金属钾呈蒸气状态不断脱离体系被冷凝抽离，促使平衡持续向右移动，产出高纯度钾（纯度 > 99.99%）[cite: 1]。

当前状态：待命已就绪，电解质为熔融 NaCl + CaCl₂ (580℃) 阳极(石墨): 2Cl⁻ - 2e⁻ → Cl₂↑ | 阴极(铁): 2Na⁺ + 2e⁻ → 2Na(l)

状态待命：锥形瓶 A (2.0 g Na₂CO₃) | 锥形瓶 B (2.0 g NaHCO₃) 动力学结论：NaHCO₃ 一步瞬间爆发生气且气球更大；Na₂CO₃ 分步延缓产气
❓ 反应本质方程式与动力学差异剖析：
• 碳酸氢钠体系（B瓶）：NaHCO₃(aq) + HCl(aq) → NaCl(aq) + H₂O(l) + CO₂(g)↑[cite: 1]
  反应一步到位，无中间过渡阶段，倒入盐酸瞬间产生剧烈翻滚气泡，气球以极快速度膨胀胀大！因相同质量下 NaHCO₃ 摩尔质量较小（84 g/mol），产出的 CO₂ 气体总体积更大！
• 碳酸钠体系（A瓶）：分步反应：
  第一阶段（盐酸不足）：Na₂CO₃(aq) + HCl(aq) → NaHCO₃(aq) + NaCl(aq)（吸收 H⁺，暂无气泡产生）
  第二阶段（盐酸过量）：NaHCO₃(aq) + HCl(aq) → NaCl(aq) + H₂O(l) + CO₂(g)↑[cite: 1]（开始平缓产气，气球膨胀较慢且体积相对较小）。
